# Dynamic 行为与参数

核对日期：2026-10-11。参考网页加载的 Chessboard 1.187.1 / Analysis 2026.9.8。以下记录具体行为，不将第三方整个网页程序打包进仓库。

| 效果 | 当前参数 |
| --- | --- |
| 抓取 | 1.25 → 1 倍，200 ms，easeOutBack |
| 拖动摆动 | 横向速度按棋格归一化，目标角度限制 ±10°，含回摆 |
| 位置移动 | 180 ms，easeInOutQuad |
| 自动移动旋转 | 270 ms；0 / 60 / 80 / 100% 时间点，角度 0 / 峰值 / −半峰值 / 0；分段 easeInQuad |
| 渐变轨迹 | 自动走棋时 180 ms 展开、300 ms 淡出；手动拖放不创建 |
| 吃子 | 被吃棋子以中心下方 90% 为原点，放大到 2 倍并在 400 ms 内淡出 |
| 落点 | 圆形 0.6 → 1.5 倍，400 ms 扩展，300 ms 透明度变化 |
| 将军 | 红格脉冲；王短暂放大与左右摇动，解除后清理 |
| 升变 | 200 ms 缩放，350 ms 双圈扩散 |
| 非法落点 | 700 ms 红色反馈；不修改棋局 |

`dynamicMotion.ts` 把缩放和旋转应用于棋子内部视觉元素。外层平移仍由 Chessground 管理，避免改变鼠标与落点的坐标关系。

`effects.ts` 管理短时效果、计时器和清理。`appMotion.ts` 将真实棋盘状态变化映射到效果，保留上游回调，不改走法合法性、判分、引擎或训练逻辑。大幅替换局面不会冒充一次吃子。

数值参考文件 `overlay/tests/fixtures/dynamic-reference.json` 保留 201 个抓取时间点、720 个连续摆动样本和 1897 个自动旋转样本；可以离线运行对照测试，无需第三方程序原文。
