# 工作清单与沿革

## 外观适配

检查 En Croissant 0.15.0 的实际应用包后，确认前端资源嵌入可执行文件，不能仅把棋子图片丢进 Resources 完成主题导入。因此基于固定上游版本添加 Neo 选择项、12 枚图片的 CSS 和绿色棋盘选择项，再构建应用。声音位于外部 Resources，可以单独替换。

## 训练内容

编写三份带中文计划的浅层开局库；筛选 600 道战术和 300 道残局；制作 12 道带提示的残局摆棋材料；整理卡帕布兰卡棋书与 597 局大师棋谱来源。该训练资料可以独立于外观补丁使用。

## 动画修正

最初依据观感制作的版本出现过偏移和不符合原版的复制棋子残影。后续将抓取缩放、摆动移到内部视觉层，保留棋盘自己的平移，并删除复制棋子的拖影。随后核对真实网页的 Dynamic 参数，加入单条渐变轨迹、吃子、将军、升变和非法落点等常规效果。

先在独立预览测试，再接入实际应用；追加真实 Chessground API 的回调、拖放/点击区分、重复更新、计时器与清理测试。发布包只保留修正后的实现；失败版本以这份说明记录，不把有已知错位的程序作为下载项。

## 声音补齐

初次动画安装仍沿用 En Croissant 标准音效，随后改用官方默认 `move-self.mp3` 和 `capture.mp3`。资产清单分别记录来源和 SHA-256；声音替换不改音量设置。其他事件声音暂未扩展。

## 打包

将环境专属路径改成可配置路径，固定上游提交，保留补丁、新增源码、公开数值测试样本、独立预览、训练生成器与数据。增加带 ZIP 备份的 macOS 安装/恢复脚本。

不发布个人对局、成绩、SQLite 设置备份、浏览器登录会话、整页抓取、原站 JavaScript bundle、未完成下载或旧应用备份。棋书和大师棋谱通过来源链接保留这部分工作；Neo 图片与原声使用本地下载步骤纳入构建。

## 0.1.1 指针修正

上游棋子的 `pointer-events: none` 让写在棋子上的 `grab/grabbing` 没有作用到真正接收鼠标的元素。改由棋盘管理悬停指针、页面管理按住期间的抓握指针，并在松手、失焦和卸载时清理；减少动态效果不影响鼠标反馈。

## 0.1.2 将军红格细边

棋盘引擎把实际棋盘宽度向下取整到可均分的物理像素，而原特效以外框为百分比定位基准。窗口宽度不整除时，红格与棋盘偏离数像素。将特效挂到实际 cg-board，沿用同一坐标系，保留原动画与颜色。新增回归检查并完成 144 组浏览器几何核验。

## 0.2.0 本地人机对弈候选版

按用户选择，以 Lichess 对局流程为参考，使用获准的引擎原生 Elo 控制。统一现有控件与文案；新增设置、赛后操作、回归与真实引擎测试。完整范围、限制及未完成验证见 COMPUTER-PLAY.md。

## 0.2.1 对弈设置文案

删除 Elo、等级、最高强度下的三句说明；Elo 标题去掉“引擎”前缀。滑块端点改为面板内左右对齐的数字，避免端点居中标签越界。

## 0.2.2 计时对局长考

前端在设置棋钟后丢弃每步时限，后端也只发送整盘剩余时间，导致低等级电脑仍长时间计算。保留人机模式的一秒预算，并与棋钟和加秒共同发送；临近超时时进一步缩短预算。高级对局原有时间管理保持不变。前端先复现配置中 go=null 的失败，再通过修复；真实 Stockfish 18 在 1.d4 后、等级 0、十分钟及带加秒条件下连续应手约 1 秒。
